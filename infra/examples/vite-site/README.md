# Site de demonstração

Node.js 24, React e Vite. `npm ci`, `npm test`, `npm run build`.

Configuração na Terabits: STATIC_SITE, build `npm run build`, teste `npm test`, saída `dist`. O Nginx gerado serve a SPA na porta 8080, incluindo rotas do navegador. Não há variáveis secretas de build/runtime neste exemplo.

Copie somente esta pasta para um repositório público de teste autorizado. Não adicionar Dockerfile ou workflow de publicação.
