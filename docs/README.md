## Organização das informações

- Atualizar o README principal quando mudar a apresentação do projeto, seus pré-requisitos ou a forma de execução.

- Manter decisões, contratos e procedimentos nos respectivos documentos técnicos, acessíveis por este índice.
- Não apresentar funcionalidades planejadas como implementadas; consultar o progresso e os contratos disponíveis.
